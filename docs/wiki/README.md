# laravel-sendgrid-driver Wiki

`laravel-sendgrid-driver` (Composer package `basharsoft/laravel-sendgrid-driver`, namespace `Sichikawa\LaravelSendgridDriver`) adds a `sendgrid` mail transport to Laravel. It turns a SwiftMailer message into a **SendGrid v3 Web API** call through `sendgrid/sendgrid` v6. It also adds two Wuzzuf-specific hooks:

- an **email checker** that drops invalid recipients
- a **testing mode** that sends every email to one test address

It is a BasharSoft fork of the open-source `s-ichikawa/laravel-sendgrid-driver`.

**How it serves Wuzzuf:** wuzzuf-platform registers it as the `sendgrid` mailer and binds its own `EmailChecker`. So transactional email can go out through SendGrid.

We wrote this wiki from the source code (`master` at `cffeec0`). We didn't use the existing README. graphify generated the [code map](code-map/index.md).

> **Read [Known issues](known-issues.md) first.** It builds on SwiftMailer and `Illuminate\Mail\Transport\Transport`, which only exist up to Laravel 8. So it blocks wuzzuf-platform's Laravel upgrade. The driver doesn't check SendGrid error responses, so failed sends look successful.

## Status

- Used: `wuzzuf-platform/composer.json:59` requires `^5.0`; `composer.lock` pins **5.2** from `git@github.com:Basharsoft/laravel-sendgrid-driver.git`. wuzzuf-platform is on Laravel 8.61 and PHP (the server language) 7.4.
- `MAIL_MAILER` in the production env decides whether production mail actually uses the `sendgrid` mailer. That value is not in the repo (`.env.example` says `smtp`). wuzzuf-platform's `FilterOutgoingEmailsListener` uses the `EmailCheckerContract` binding either way.
- Last push 2026-01-31 (same day as the other BasharSoft PHP packages).
